# UFC-SA - Página Web Temática UFC

## 🥊 Descripción
Página web con temática de UFC que muestra categorías de combate, rankings oficiales y próximos eventos.

## ✨ Características
- Diseño full responsive
- Temática UFC con colores rojo/negro/naranja
- Navegación con scroll suave
- Tarjetas interactivas con imágenes de fondo
- Rankings de peleadores
- Próximos eventos

## 🛠️ Tecnologías
- React 18
- Vite
- CSS-in-JS (inline styles)

## 🚀 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/TU-USUARIO/TU-REPOSITORIO.git

# Entrar al directorio
cd TU-REPOSITORIO

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
